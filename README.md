# 🎬 Movies Watchlist

A simple and interactive movie watchlist application built with React. It allows users to keep track of movies, write personal reviews, and rate their favourite films.

## ✨ Features

- **Add Movies:** Add movies to your watchlist by entering their titles.
- **Write Reviews:** Share your thoughts and personal reviews about each movie.
- **Rate Movies:** Rate movies on a scale of 1 to 5 stars.
- **Delete Movies:** Remove movies from your watchlist whenever you want.
- **Interactive UI:** A clean and user-friendly interface.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- HTML5
- Vite

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Tasneem-Mohamed137/movies-watchlist.git
```

### 2. Navigate to the project directory

```bash
cd movies-watchlist
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
